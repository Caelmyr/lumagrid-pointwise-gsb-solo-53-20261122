# LumaGrid 面板光学台

在本地登记面板和相机采集，使用固定标定版本执行光学检查，保留源图、检查结果和复核决定。

## 启动

在此目录执行 `./start.sh`，打开本机 `http://127.0.0.1:19956/`。需要 Docker Engine 和 Compose，首次构建使用 Python 3.11 slim 基础镜像并安装 `requirements.txt` 中锁定的依赖。已有 Docker 自定义构建器时也可通过环境变量 `BUILDX_BUILDER` 指定。端口由 `LUMAGRID_PORT` 设置，资料写到 Compose 命名卷。保留卷即可重建容器，`docker compose down -v` 会删除本项目数据。

普通 Python 3.11 环境也可安装依赖后从该目录执行 `LUMAGRID_DATA=/绝对/数据目录 python -B -m lumagrid`。环境变量 `HOST` 与 `PORT` 控制监听。请使用独立数据目录，不让开发副本共享运行库。

## 操作

1. 打开合成演示，或新建面板并导入相机采集。原图支持 PNG、JPEG、单帧 TIFF。允许灰度或 RGB。录入角色、快门、观察角和带时区的采集时间，便于选取参照。
2. 选择采集，按顺序点击左上、右上、右下和左下保存标定。在检查页选择标定版本、可选对照采集和选区，运行检查。
3. 保存检查后打开复核与交接，录入复核决定。已复核记录可下载 ZIP 并回读校验。采集包页处理包含原图、属性与标定的本地资料移动。
4. 时钟配对支持带 `timestamp,event,level` 字段的参考 CSV，其中 `level` 可缺。镜头校正页接受相同设置、相同像素尺寸下的暗场与平场。

## 工具

| 采集坐标 | 亮度与颜色 | 图案与采样 | 对照与采集质量 |
| --- | --- | --- | --- |
| 展平 | 空间均匀性 | 灰阶传递曲线 | 盖板反射复核 |
| 端点量测 | 低黑位漏光 | 斜边清晰度 | 相机曝光余量 |
| 采集重叠检查 | 视角色偏 | 面板剖面 | 相机固定亮点 |
| 几何检查点校验 | 棋盘格对比 | 空间条纹频谱 | 重复采集稳定度 |
| 像素探针 | 局部切换差分 | 次像素近摄 | 镜头平场渐晕 |
| 采集残余位移 | 有效画面边界 | 定点屏缝剖面 | 暗平场校正 |

每张图最多 24 MiB 和 1600 万像素。透明或投影范围外的样本在需要时排除。工具运行使用有界的工作分辨率；原像素式工具另外限制工作窗口。工作库默认限额为 2 GiB 材料内容。合成材料用于演示。相对码值或 sRGB 假设色差不能作为实际面板出厂认证。
